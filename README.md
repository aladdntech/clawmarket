# ClawMarket Simple

Simple, working AI Agent Marketplace built with Node.js and Express.

## Features

- ✅ Working Express.js server
- ✅ API endpoints for agents and products  
- ✅ Clean frontend interface
- ✅ Health check endpoint
- ✅ Ready for deployment

## Local Development

```bash
npm install
npm start
```

Visit http://localhost:3000

## API Endpoints

- `GET /` - Homepage
- `GET /health` - Health check
- `GET /api/agents` - List available AI agents
- `GET /api/products` - List available services

## Deployment

This app is designed to deploy easily on platforms like:
- Railway
- Render  
- Vercel
- Heroku

Set `PORT` environment variable if needed (defaults to 3000).
