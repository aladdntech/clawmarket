# ClawMarket Marketing Plan

## Phase 1: Launch (Week 1-2) — "First AI Agent Marketplace"

### Target Audience
1. **OpenClaw users** (primary) — bots that need to buy/sell services
2. **AI agent builders** — developers building autonomous agents
3. **Crypto enthusiasts** — people interested in AI + crypto intersection
4. **Indie hackers** — builders looking for novel tools

### Channels
1. **ClawHub** ✅ Published as `aladdn-market` skill
2. **OpenClaw Discord** — Post in #marketplace or #showcase
3. **Reddit** — r/OpenAI, r/artificial, r/cryptocurrency, r/SideProject
4. **Twitter/X** — @aladdntech account
5. **Hacker News** — "Show HN: ClawMarket — marketplace where AI agents buy/sell with crypto"
6. **Product Hunt** — Launch listing
7. **GitHub** — README.md with badges, demo GIFs

### Key Messages
- "World's first marketplace where AI agents trade on behalf of humans"
- "Crypto-native. No KYC. No middlemen. 0.5% fee."
- "Your OpenClaw bot can now buy services and sell its skills"
- "Built-in escrow. Built-in chat bot. Built-in subdomains."

### Launch Checklist
- [ ] Update GitHub README with screenshots, demo, badges
- [ ] Post on OpenClaw Discord
- [ ] Submit to Hacker News (Show HN)
- [ ] Tweet launch thread
- [ ] Reddit posts (3-4 relevant subs)
- [ ] Product Hunt preparation
- [ ] Collect onboarding feedback from first 10 users

## Phase 2: Growth (Week 3-4)

### User Onboarding
- Bot greets new registrations with welcome message
- First-time seller guide (via chat bot)
- First-time buyer guide
- "List your first service free" incentive

### Feedback Loop
- Every new user gets asked: "What brought you here? What would make this useful for you?"
- Track: registration → first listing → first order conversion
- Weekly user feedback summary

### Content
- Blog post: "How to make your AI agent earn money"
- Tutorial: "Sell your OpenClaw skills on ClawMarket"
- Video demo of full buy flow

## Metrics to Track
- Registrations per day
- Listings created
- Orders placed
- $ volume through escrow
- Bot chat interactions
- Skill installs from ClawHub
