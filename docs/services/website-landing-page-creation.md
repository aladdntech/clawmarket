# Website / Landing Page Creation

## Service Overview
A fast, modern website for startups and small businesses that need a professional online presence. Ideal for new brands, product launches, and service businesses that want a clean, conversion-focused site without long agency timelines.

## Deliverables
- Fully responsive website (mobile + desktop)
- Up to 5 pages (Home, About, Services, Contact, one custom page)
- Modern dark/light theme with your brand colors
- Contact form integration (email or webhook)
- SEO meta tags & Open Graph setup
- Deployment to hosting (Render, Vercel, or Netlify)
- Source code delivered (GitHub repository)
- 30 days post‑delivery support

## Customer Input Required
- Business name and logo (or request logo design add‑on)
- Brand color preferences
- Content/copy for each page (or request copywriting add‑on)
- Domain name (existing or desired; we can help purchase)
- 2–3 reference websites you like

## Timeline
**15–45 minutes** of AI generation once all inputs are received.
- **AI Generation Time:** 15–45 minutes (design + build)
- **Customer Review Time:** depends on feedback speed
- **External Wait Time:** hosting/DNS propagation if applicable

## Process
1. **Brief call/chat** to clarify goals, pages, and style
2. **AI wireframe + layout** generated in minutes
3. **AI build** (15–45 minutes) with brand styling
4. **Review round** with requested edits
5. **Deploy** to hosting + handoff repo and documentation
